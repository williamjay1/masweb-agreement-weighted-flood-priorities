# WBD source and HUC8 assignment check

The original HUC8 sensitivity grouped candidate counties using a cached USGS National Map Watershed Boundary Dataset snapshot dated 3 August 2026 UTC. The archive records layer 6, **12-digit HU (Subwatershed)**, and stores its official service metadata, feature query parameters and response SHA-256 hashes. The manifest dates record retrieval or reuse. The archive labels the inputs as reused, so this date identifies the frozen snapshot while the date of first access remains unknown. The stored service metadata does not identify a numeric release of the WBD geometry. Its `currentVersion` value identifies the service software.

- `wbd_source_manifest.csv` lists the official [layer endpoint](https://hydro.nationalmap.gov/arcgis/rest/services/wbd/MapServer/6), request parameters, and verified hashes for the cached responses associated with the five primary events. Paths are relative to the original snapshot directory.
- `wbd_query_log.csv` identifies the queried WGS84 envelopes and their returned feature counts.
- `wbd_layer6_metadata.json` is the retained source service metadata.
- `assignment_verification.json` identifies the exact five combined geometry files by SHA-256 and records the identity check of all 37 original county assignments, including the fallback selection method. The five event block counts are 4, 2, 4, 8 and 8 in manuscript event order.

Extract the five frozen combined geometries with python -m zipfile -e frozen_geometry.zip . from this directory. The archive preserves the exact bytes and restores the frozen_geometry/ paths. The original county polygon layer must be obtained separately and matched to the documented SHA-256. The WBD service can change, so a fresh query must be compared to the archived hashes before treating it as the same input. From this directory, run `python verify_wbd_assignments.py --wbd-root frozen_geometry` with Python 3.11 or later and Shapely installed. The script uses the packaged county geometry and assignment table with each event's combined `event_huc12.geojson`, dissolves HUC12 features by the first eight digits of the code and checks each county centroid assignment. It uses the nearest dissolved watershed when no candidate geometry covers the centroid. The full R2 block analyses can also be rerun directly from the packaged assignment table without the upstream WBD polygons.
