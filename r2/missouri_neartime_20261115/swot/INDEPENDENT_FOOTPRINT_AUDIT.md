# Independent SWOT nominal-footprint audit, 15 November 2026

The analysis audited swot_cmr_footprints.py, compare_swot_footprints.py, the retained CMR UMM JSON, ISO XML source polygons and the 5,661-row optical sample CSV, without modifying them. Independent recomputation used Shapely geometry and pyproj.Transformer.from_crs(5070,4326,always_xy=True).

- The input CSV has 5,661 rows and 5,661 distinct x/y pairs. Transformed longitudes range -94.10666 to -92.53881, and latitudes 36.50351 to 37.82844, consistent with the original study rectangle.
- ISO polygons have coordinate pairs expressed latitude then longitude. The original parser reverses each pair to construct Shapely longitude/latitude polygons. All 25 generated geometry bounding boxes matched their independently supplied UMM west/south/east/north bounding rectangles to within 1e-8 degrees. This is evidence against an axis-order error in these input polygons, not a statement about geolocation uncertainty.
- Within the queried collection there were 25 granule records, sorted by pass: 033_244 had 5; 033_259 had 16; 033_272 had 4. The 16 records of pass 033_259 are 8 tiles, each available as PID0_01 and PID0_02. All 8 version pairs produced topologically equal nominal polygons, with zero symmetric-difference area. A geometry union was made before counting sample points; counting using only one version per tile gave exactly the same result.
- Independent union counts were 751 for 033_244, 2,521 for 033_259 and 1,887 for 033_272, identical before and after removal of the repeated nominal polygons. These are sample-centre inclusions in nominal ISO exterior polygons, including boundary points via covers; they are not counts of valid SWOT observations, classified flood pixels, or verified dry ground. No PIXC data were read for this audit.
- In chronological order, 033_244 began 2025-05-27 14:12:29.516 UTC; the two passes with 2,521 and 1,887 centres are 033_259 and 033_272, beginning 2025-05-28 03:25:55.128 and 14:13:00.634 UTC, respectively. Each pass has multiple granule start times; the times above are minima. The existing calculation uses S30 2025-05-30 16:58:49 UTC as reference; L30 acquisition time is different. No implication of same-day observation should be made.

All 25 queried records are within the single queried collection C3233944986-POCLOUD; this audit does not search other collections or establish that all possible versions are represented. PID0_01 and PID0_02 are duplicate footprint geometries in this search; their science data contents were not compared and must not be treated as interchangeable based solely on this result.
