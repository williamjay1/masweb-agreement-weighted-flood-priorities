# Missouri NOAA VIIRS comparison plan, established before extracting the VIIRS observations

Fixed input: 5,661 strict-common eligible S30 and L30 30 m pixel centres from existing `rtc_may26_point_samples.csv`; optical acquisitions 2025-05-30 16:58:49 / 16:48:07 UTC. No additional cherry-picking by flood class or NOAA outcome. Compare NOAA VIIRS 1-day GLB019 v2r0 for 2025-05-30 first, with May 29 and May 26 as time-sensitivity diagnostics only, not independent validation of May 30.

EPSG:5070 pixel centres will be transformed using `always_xy` to TIFF EPSG:4326, sampled by source row and column. First report frequency for each original categorical value separately on 30 m centre and unique source-grid-cell bases. Count code 1 as no valid, code 30 as cloud, code 50 shadow; other codes explicitly. Use no interpolation of categorical values. Do not assume a coarse cell has the same value for all of its area. TIFF source-grid spacing is 0.0033723 degrees (source native nominal 375 m), longitude and latitude distances differ.

Source-document crosswalk: code 15 is floodwater without retrieved fraction; 16 bareland; 17 vegetation; 99 normal water; codes 100–200 flood water fractions; 20,27,38 frozen water/ice or mixtures. Record each observed code, particularly code 100 independently because the manual does not establish whether that particular value represents exactly zero fraction. On coarse-cell results separately summarize any S30 and any L30 positive among the *sampled 30 m centres* in the source cell; this is an exploratory spatial concordance diagnostic, not area-complete retrieval or a remotely sensed accuracy measure. Never interpret counted 30 m centres as independent VIIRS evidence; coarse cells themselves are not necessarily statistically independent of each other. Version, timestamps, source URLs and original file SHA256 will be recorded. All analyses restricted to this preexisting valid sample, not the full Missouri AOI. Coarse sensor classification uses different water definitions, prior-water data, viewing and timing; it is not ground truth nor independent SAR validation.
