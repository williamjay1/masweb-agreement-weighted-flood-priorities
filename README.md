# Agricultural flood priorities: analysis data and code

Version 1.1.0 archives the analyses added in the second revision of this study. Start with [r2/README.md](r2/README.md) for the data dictionary, source requirements and commands. [r2/SHA256SUMS.txt](r2/SHA256SUMS.txt) identifies the exact release files.

The earlier derived inputs, analyses and figure files are archived independently as version 1.0.5 at [Zenodo 23240366](https://doi.org/10.5281/zenodo.23240366). Cite the version specific DOI of the files used. The [series DOI](https://doi.org/10.5281/zenodo.23238975) identifies all versions.
